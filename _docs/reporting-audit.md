# Reporting and audit

Reports are Admin-only. Current owner metrics use the present customer owner and lifecycle state; open never-contacted counts use imported contact history. Interaction totals count nondeleted Attempt and Contact events in an inclusive UTC date range. Contact rate is Contacts divided by Attempts; zero Attempts displays `N/A`. Daily rows are zero-filled. Audit is newest-first and uses safe event metadata only; deleted note bodies and credentials are never exposed.
